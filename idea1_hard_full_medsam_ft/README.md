# Idea1 Hard-Full MedSAM Fine-tuning

This directory is an **additive implementation** for the frozen MedSAM→Swin-UMamba baseline.
It does not import or reuse the historical SAC/bank/shape pipeline.

## 1. Method contract

- Round 0:
  - 2D: random 5 foreground training images, seed 2026.
  - 3D: random 1 foreground training case, seed 2026.
- Later rounds:
  - 2D: add up to 5 images with `image_macro_iou < 0.5`, maximum 20 Full images.
  - 3D: add 1 case per round; maximum `max(1,min(5,ceil(0.05*N_train_cases)))`.
- MedSAM:
  - image encoder frozen;
  - prompt encoder frozen;
  - mask decoder trainable;
  - `Dice + BCEWithLogits` only.
- Pseudo labels:
  - generated by the repository's frozen `generate_pseudo_labels.py` in an isolated generation view;
  - no double threshold, bank, shape, half-shell or additional weak loss.
- Student supervision:
  - Full samples use exact student-space GT;
  - remaining Box samples use final fine-tuned MedSAM tri-state pseudo;
  - output is `pseudo_student/tri_train_idea1_hard_full_medsam_ft`.

## 2. Why baseline cannot be overwritten

The implementation creates separate paths:

```text
tri_train_boxonly
tri_box_final_idea1_hard_full_medsam_ft
tri_train_idea1_hard_full_medsam_ft
```

The frozen baseline paths remain unchanged:

```text
<original processed>/pseudo_student/tri_train
<original Swin work_dir>/baseline
<original Swin work_dir>/upper
```

## 6. Run teacher iteration

```bash
IDEA_FOLD=/storage/baiyuting/data/out_data_idea1/MedSAM-main/data/processed/tg3k/fold_0

python idea1_hard_full_medsam_ft/run_iterative_teacher.py \
  --repo_root /storage/baiyuting/data/out_data_idea1/code/idea1_hard_full_medsam_ft/MedSAM-main \
  --fold_root "$IDEA_FOLD" \
  --dataset tg3k \
  --fold fold_0 \
  --method idea1_hard_full_medsam_ft \
  --base_checkpoint /storage/baiyuting/data/MedSAM-main/work_dir/MedSAM/medsam_vit_b.pth \
  --device cuda \
  --seed 2026 \
  --steps_2d 300 \
  --steps_3d 1000 \
  --batch_size 2
```

`batch_size=2` is implemented as gradient accumulation over physical SAM microbatches of one pair, avoiding incorrect multi-image expansion inside the SAM mask decoder.

Read the final round from:

```text
<IDEA_FOLD>/meta/teacher_iteration_final_idea1_hard_full_medsam_ft.json
```

## 10. Reproducibility rules

- Never use test GT for selection, fine-tuning or pseudo generation.
- Never change probability threshold from 0.5 in this method.
- Never write into the frozen baseline `tri_train`, baseline work directory or upper work directory.
- 3D selection unit is a complete case.
- Full case means all slices use GT for student supervision.
- 3D evaluation must use the repaired real `spacing_zyx`.
- One-sided empty prediction: Dice 0; HD95/ASSD NaN; report the empty-prediction failure count separately.
